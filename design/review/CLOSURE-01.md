**F01-002 and F01-003: one coherent protocol — FAIL.**

There is one intended abstraction: `G-9` ([domain-model.md:888](../domain-model.md#L888)), one external-effect ordering rule ([evidence-model.md:151](../evidence-model.md#L151)), and one kernel capability, `recovery.reconcile` ([authority-matrix.md:94](../authority-matrix.md#L94)). A provider key and a repository token are legitimate backend-specific identities. Their different lookup mechanisms do not, by themselves, constitute divergent protocols. The detailed specifications nevertheless fail to implement one consistent recovery contract:

| Recovery case | Worker rule | Commit rule | Closure consequence |
|---|---|---|---|
